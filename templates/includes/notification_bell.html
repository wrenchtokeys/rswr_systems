Usage: {% include "includes/notification_bell.html" with bell_role="customer" %} {% include "includes/notification_bell.html" with bell_role="tech" %} Expects `unread_count` and `recent_notifications` in context. Two rules this file exists to hold: 1. **The poll reconciles, it does not replace.** The old version rewrote innerHTML every 30 seconds unconditionally. Two things fell out of that: the click handlers were bound once at load, so after the first tick clicking an unread row silently stopped marking it read; and a reader who had the panel open watched the list rebuild under their cursor. Now rows are handled by delegation (they survive any re-render) and a re-render is skipped entirely while the panel is open — the payload is held and applied on close. 2. **The server renders the rows.** The endpoint returns finished HTML from components/notification_list.html rather than JSON this file re-templates. {% endcomment %}
